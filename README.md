# House of Yahara 🏡

### Curated Spaces. Timeless Living.

A premium interior design website created to showcase
beautifully curated spaces and a refined living experience.

## 🌐 Live Demo

https://house-of-yahara-production.pages.dev/

## 🛠️ Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Framer Motion
- React Router
- Lucide React

## ✨ Features

- Premium responsive design
- Smooth animations and transitions
- Modern UI/UX
- Responsive layouts
- Interactive navigation
- Supabase integration
- Mobile-friendly experience

## 🚀 Getting Started

npm install

npm run dev
